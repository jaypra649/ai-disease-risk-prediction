# AI-Based Diabetes Classification System

An AI-based healthcare project that uses machine learning to classify diabetes status from health-related data, with a planned Java Spring Boot backend integration.

## 🎯 Objective

To explore machine learning for diabetes classification and build a full-stack application integrating Python-based ML with Java backend technologies.

## ✨ Features

- Data preprocessing and missing-value handling
- Logistic Regression classification
- Model evaluation using cross-validation and performance metrics
- Classification threshold comparison
- Planned REST API integration using Java Spring Boot
- Planned web interface and MySQL database integration

## 🛠️ Tech Stack

**Machine Learning**
- Python
- Pandas, NumPy, Scikit-learn
- Google Colab

**Backend (Planned)**
- Java
- Spring Boot
- REST APIs

**Frontend and Database (Planned)**
- HTML, CSS, JavaScript
- MySQL

**Version Control**
- Git and GitHub

## 📊 Model Evaluation

The Logistic Regression model achieved an out-of-fold ROC-AUC of **0.835** using stratified 5-fold cross-validation.

Additional evaluation includes accuracy, precision, recall, specificity, and classification threshold comparison.
